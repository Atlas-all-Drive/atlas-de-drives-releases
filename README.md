# Atlas de Drives — versões

Este repositório distribui as versões do **Atlas de Drives**, um catálogo local de HDs e SSDs externos para macOS.

- O Atlas **só lê** nomes, tamanhos e datas dos seus drives. Nunca apaga, move ou altera nada.
- Funciona **sem internet**. Seus dados ficam no seu computador.
- Para baixar a versão mais recente, veja a aba **Releases** deste repositório.

**Requisitos:** Mac com chip Apple (M1, M2, M3 ou M4) e macOS 12 ou mais novo.

**Instalação:** abra o `.dmg`, arraste o Atlas de Drives para *Aplicativos* e, na primeira vez, abra com botão direito → *Abrir* (o app não é assinado pela Apple).

O arquivo `latest.json` é lido pelo próprio Atlas (botão *Verificar atualizações*, na aba *Avançado*) para avisar quando há versão nova. O código do programa não está neste repositório.
